# Publish application code with a private operational boundary

Publish Flipper under MIT through the existing repository with reset public
history. Preserve the prior history privately and publish only source, synthetic
tests, portable instructions and resolved design decisions. Runtime seller data,
credentials, private host configuration, personal author email and operational
receipts remain outside the published tree. Use a public no-reply commit identity.
TechAPI-derived datasets retain CC BY-SA 4.0 attribution separately from code.

A same-repository history reset replaces reachable branch history; it does not
promise removal of GitHub's retained commit objects or existing clones. Publication
verification must distinguish a clean public tree/history from cache purging.
