# Evidence-based valuation and durable personal state

Complete-configuration references are preferred. Component-adjusted comparisons
may substitute independently supported GPU/RAM/storage terms within the same
desktop CPU/platform, or replaceable RAM/storage within a source-verified laptop
configuration. Base-PC and part-pool independence remain separate. Missing base
component documentation reduces confidence and is shown, but does not itself
block scoring when the arithmetic inputs are supported. Asking-price evidence
expires after 24 hours. SQLite persists observations, history, settings, saved
searches and reversible personal state. Partial failures retain observed evidence
and expose uncertainty rather than manufacturing a current score.
